# ImageViewer 开发说明

## 技术与模块

项目继续使用 .NET 10、WPF、CommunityToolkit.Mvvm 和 OpenCvSharp，不引入新的图像或缩放库。

| 模块 | 职责 |
| --- | --- |
| `App` | 注册单例 `ImageModel`、`MainViewModel`，在窗口完成布局后打开启动参数指定的文件，退出时释放容器 |
| `MainWindow` | 分类菜单、状态栏；窗口级快捷键与单文件拖放 |
| `ImageInputWindow` | 倍率、Gamma、ROI 的输入对话框，确认时调用现有 ViewModel 命令 |
| `MainViewModel` | 操作命令、视口计算、选区状态、输入反馈和原始像素读数 |
| `ImageModel` | 原始 Mat、显示基础缓存、Gamma/Jet、像素读取和 ROI 统计 |
| `ImageCanvasControl` | WPF 绘制、鼠标捕获、交互期间采样策略、像素文字缓存 |

当前没有 `ImageService`。ViewModel 直接使用容器提供的 `ImageModel`。

## 数据流与资源所有权

```text
打开 / 拖入 / 启动参数
    → MainViewModel.LoadImage
    → ImageModel.Load
        → 解码候选 Mat
        → 构建 8 位显示基础
        → 创建冻结 BitmapSource
        → 全部成功后替换旧图，释放旧资源
    → 清除旧选区并设置初始视口
    → RenderRequested → InvalidateVisual → OnRender
```

所有图片统一使用 `Cv2.ImRead(Unchanged)`，仅支持当前 OpenCV 构建能够解码的图片，不再提供 ICO 专用解码。GIF、TIFF 等文件当前只显示单帧，不提供动画或多页浏览。

原始 Mat 始终用于状态栏和 ROI 统计。8 位图像的显示基础使用共享存储的独立 Mat 头；非 8 位图像只在加载时归一化一次。32/64 位浮点显示副本内的 NaN/Inf 替换为零，原始值保留。

显示流程为 `8 位基础 → Gamma → 可选 Jet → 冻结 BitmapSource`。Gamma 使用 `255 × (v/255)^gamma` 的查找表；BGRA 图的 Alpha 不参与校正。显示参数重复应用相同值时不重建位图。

图像加载入口统一处理失败并通过顶部错误提示反馈，失败保留旧图、视口和选区。模型用 `finally` 释放尚未提交的候选资源。容器退出时释放原始 Mat 和显示缓存。

## 坐标与视口

原图左上角外边界为 `(0, 0)`，右下角外边界为 `(Width, Height)`；整数 `(x, y)` 对应像素中心 `(x+0.5, y+0.5)`。图片、网格、ROI 和十字线使用相同坐标约定，不再分别添加半像素偏移。

```text
sourceX = ShowX + canvasX / ImgScale
sourceY = ShowY + canvasY / ImgScale
canvasX = (sourceX - ShowX) × ImgScale
canvasY = (sourceY - ShowY) × ImgScale
ShowW = CanvasWidth / ImgScale
ShowH = CanvasHeight / ImgScale
```

状态栏像素索引取 `Floor(sourceX/sourceY)`。图外和离开画布时清空像素读数；在同一个像素内移动不重复读取。十字线位于原图几何中心 `(Width/2, Height/2)`。

所有倍率入口使用 `SetViewport` 固定锚点，滚轮因子为 `1.1^(Delta/120)`。正负相同增量互为倒数，未触及倍率或可见范围边界时可往返恢复。平移与 `SetViewport` 均调用 `ConstrainViewport` 限制位置；触及边界时优先保证图片可见，允许锚点移动。

| 操作 | 锚点 / 模式 |
| --- | --- |
| Auto | 图像中心映射到画布中心；尺寸变化继续适配 |
| 1:1 | 图像居中，倍率 1；退出自动模式 |
| 输入倍率 | 保留当前原图视口中心；退出自动模式 |
| 滚轮 | 保留鼠标下方的原图位置；退出自动模式 |
| 平移 | 以 DIP 位移除以倍率更新 ShowX/Y；限制在可见范围内 |
| 手动模式尺寸变化 | 优先保留原图视口中心和当前倍率，随后应用倍率与可见范围限制 |

所有缩放入口共用倍率限制：最大 50，最小为 `Min(1, 50 / Max(Width, Height), CanvasWidth / Width, CanvasHeight / Height)`。通常将缩小后的图片长边限制为至少 50 DIP，原图长边不足 50 时不再缩小；画布更小时允许缩到完整适配，避免从 Auto 切换手动缩放时向上跳变。平移、缩放和画布尺寸变化后，横纵方向分别至少保留 `Min(50, 画布尺寸, 图片显示尺寸)` DIP 的图片可见。1:1 表示一个原图像素对应一个 WPF DIP，不保证高 DPI 屏幕上的物理像素一一对应。

## ROI 状态和鼠标生命周期

| 状态 | 含义 |
| --- | --- |
| `IsSelectRoi` | 是否启用左键选区工具 |
| `IsDrawingRoi` / `RoiPreviewRect` | 本次尚未提交的拖动预览 |
| `HasRoi` / `RoiRectOnSrc` / `RoiInfoText` | 上次确认的选区和统计 |
| `IsPanning` | 右键平移正在进行 |

只有在图内开始 ROI 才捕获鼠标。框选包含起点、终点像素，支持任意方向，单击生成 1×1 ROI。拖动过程中只更新预览，松开时调用一次 `GetRoiStatistics`，同次扫描计算均值、最小值、最大值并跳过 NaN/Inf。

关闭 ROI 工具保留选区。Esc、窗口失活、捕获丢失或布局变化会结束未提交操作，原选区保留；无拖动时 Esc 清除 ROI 和十字线。切换视口模式也会结束拖动。手动 ROI 输入合法后裁切宽高并回填，非法输入不替换已有选区。

统计作为不拦截鼠标的叠加层显示在画布左上角，选区移出视口时仍可查看；彩色图显示各通道均值，单通道额外显示 Min/Max。

## 绘制与缓存

1. 始终按完整图像的目标矩形绘制，使用画布裁切，不在滚轮事件内裁剪或生成放大 Mat。
2. 默认放大采用最近邻；开启平滑后，30 倍以下的放大使用平滑采样。
3. 平滑缩放或缩小的连续交互期间采用 `LowQuality`，停止 150 ms 后恢复 `HighQuality`；右键松开立即恢复。
4. 30 倍起绘制整像素网格，50 倍绘制原始像素文字，只遍历可见图内像素。
5. 缓存 `FormattedText` 和前景色；图片、Gamma/伪彩色结果、DPI、文字背景变化时清理，超过 8192 条后在下次绘制清理。十字线、ROI 预览与确认选区共用画笔，倍率低于 1 倍时为 1 DIP，1 倍至低于 10 倍时为 1.5 DIP，10 倍至低于 30 倍时为 2 DIP，30 倍及以上为 3 DIP，仅在颜色或线宽档位变化时重建。
6. 控件卸载时停止计时器、解除 ViewModel 订阅并释放文字与位图缓存引用；重新加载时恢复订阅。

## UI 与命令

顶部使用 WPF 原生 Menu/MenuItem，按文件、视图、显示、ROI、帮助分类；叠加颜色使用嵌套子菜单。开关项的 IsChecked 以 OneWay 绑定 ViewModel 状态，实际切换由现有命令执行，避免菜单自动勾选与命令重复修改状态。颜色菜单在点击时同步颜色和互斥勾选。无图时禁用图像操作，非单通道图禁用伪彩色；打开失败仍在菜单下方提示。

倍率、Gamma、手动 ROI 通过菜单 Tag 指定输入区域，打开同一个 ImageInputWindow。各区域在 XAML 中独立声明，未确认的输入保存在对话框控件中；确认时交给 ApplyScale、ApplyGamma、ApplyCustomRoi 命令处理，校验失败时在对话框中提示，成功后关闭。未引入菜单数据模型、服务接口或新的计算流程。新增普通功能时，在 MainWindow.xaml 的对应分类下添加 MenuItem 并绑定命令；需要输入时可添加独立输入区域或相应视图。

底部固定 26 DIP 高度，分为左侧 55% 与右侧 45% 两组。左侧为缩放率、像素坐标和像素值，右侧为图像类型、尺寸和完整路径；鼠标读数长度变化不改变右侧分组位置。两组内前两列自动宽度，末列使用剩余空间，空间不足时省略并提供完整悬浮提示。底部不显示操作提示、按钮或 ROI 统计。

窗口处理 Ctrl+O、Ctrl+0、Ctrl+1、Ctrl+方向键、R、C、Esc。菜单获得键盘焦点或有顶层子菜单打开时，窗口将按键交给原生菜单处理，Esc 优先关闭菜单。输入对话框使用默认按钮承接 Enter、取消按钮承接 Esc，不受主窗口查看快捷键影响。

## 构建与验证

```powershell
dotnet build ImageViewer.slnx --no-restore
dotnet run --project tests/ImageViewer.Probe/ImageViewer.Probe.csproj --no-restore
```

首次构建需先 `dotnet restore ImageViewer.slnx`。探针在 Windows STA 线程生成测试图，验证视口锚点、倍率解析、选区、失败保留、透明度、浮点数据、采样计时器、缓存复用及实际绘制坐标；并输出正常窗口、720 DIP 窄窗口、高倍率像素图等离屏 PNG。

`tests/` 已加入 Git 忽略规则，探针仅在本机保留，不纳入解决方案。新克隆的仓库不包含该目录；主程序构建不依赖探针，以上探针运行命令仅适用于本机存在相应文件的情况。

输出位于探针的 `bin/Debug/net10.0-windows/probe-output/`。离屏耗时只用于调试参考，不代表真实桌面的交互帧率。自动验证不能替代实际鼠标/键盘、不同 DPI、多屏和超大图体验检查。

图片加载、Gamma 转换和 ROI 统计当前仍在界面线程执行；本次未增加异步图像所有权或分块图像系统。若超大图成为实际瓶颈，应先测量耗时和内存，再决定是否增加后台加载或多分辨率缓存。
