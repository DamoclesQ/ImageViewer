# ImageViewer 用户说明

## 菜单分类

顶部采用标准菜单栏，点击分类展开功能，带勾选标记的菜单项表示当前已启用的功能。

| 菜单 | 功能 |
| --- | --- |
| 文件 | 打开图片 |
| 视图 | 自动适配、原始大小 1:1、指定缩放比例、平滑缩放 |
| 显示 | 调整及重置 Gamma、Jet 伪彩色、中心十字线、像素文字背景、叠加颜色子菜单 |
| ROI | 框选工具、手动设置、清除 ROI、清除选区和十字线 |
| 帮助 | 关于 ImageViewer |

倍率、Gamma 和手动 ROI 在独立对话框中输入，按 Enter 或点击“确定”应用，点击“取消”放弃本次未应用输入。输入不合法时对话框保留并提示错误。菜单支持 Alt 访问键和方向键导航；菜单打开时 Esc 优先关闭菜单。

## 打开图片

选择“文件 → 打开图片”、按 Ctrl+O，或将单个文件拖入窗口。也可以通过启动参数传入文件路径。

仅支持当前 OpenCV 构建能够解码的图片，常见格式包括 BMP、JPEG、PNG、TIFF 和 GIF。其他 OpenCV 支持的格式可通过“所有文件”、拖放或启动参数打开；不再提供 ICO 专用解码支持。GIF 和多页 TIFF 当前只显示单帧。

大图初始自动适配，小图初始 1:1。打开失败时顶部工具区显示错误，之前的图片和选区保留。

## 缩放和平移

| 操作 | 行为 |
| --- | --- |
| 视图 → 自动适配 / Ctrl+0 | 自动适配，调整窗口后继续适配 |
| 视图 → 原始大小 1:1 / Ctrl+1 | 原图像素对应一个 WPF 显示单位并居中；高 DPI 下不等于物理像素比例 |
| 视图 → 指定缩放比例 | 输入 100、150% 或 2x；以当前视口中心缩放 |
| 鼠标滚轮 | 以鼠标所在位置缩放，向上放大、向下缩小 |
| 右键拖动 | 平移图像 |
| Ctrl+方向键 | 向相应方向移动查看区域；输入框内仍用于文字编辑 |

手动缩放和平移后退出 Auto 模式。手动模式调整窗口时优先保留原图视口中心与倍率，再应用可见范围和倍率限制。最大倍率为 50 倍。

平移、缩放和窗口变化后，图片在横纵方向各至少保留 50 DIP 可见；某方向的图片或画布不足 50 DIP 时，保留该方向可容纳的完整图片尺寸。触及边界后无法继续向外移动，缩放时也不会让图片完全离开画布。

最小缩放通常限制为缩小后长边至少 50 DIP；原图长边不足 50 像素时最低为 1:1。若画布更小，则允许缩到完整适配。滚轮和倍率输入框采用相同限制，超出范围时自动使用边界倍率并回填输入框。

默认放大采用最近邻，便于查看像素。选择“视图 → 平滑缩放”可以平滑浏览；30 倍起自动回到像素显示并绘制网格，50 倍显示各通道原始数值。

## 像素和显示调整

底部固定为单行，左侧显示缩放率、原图像素坐标和像素值，右侧显示图像类型、图像尺寸和完整图片路径。鼠标到图外或离开画布时清空坐标与像素值，右侧图像信息保持原位。

状态栏像素值直接用圆括号包裹数值，不显示通道名称前缀，例如单通道 `(128)`、三通道 `(12, 34, 56)`、四通道 `(12, 34, 56, 255)`。多通道数值按 OpenCV 的 B、G、R、A 顺序排列；单通道 ROI 均值标签显示 Value。浮点值中的 NaN/Inf 会明确标注。长路径和像素值空间不足时省略显示，悬停可查看完整内容。

“显示”菜单提供以下调整：

- “调整 Gamma”：输入后按 Enter 或“确定”；范围 0.05～20，小于 1 提亮，大于 1 压暗；“重置 Gamma”恢复为 1。
- “叠加颜色”：从子菜单选择红、绿、蓝色，用于十字线和 ROI 边框。
- “像素文字背景”：调整 50 倍像素数值的可读性。

单通道图片还可选择“显示 → Jet 伪彩色”切换 Jet 显示。非 8 位图像归一化为 8 位用于显示。上述调整均不改变原始像素和 ROI 统计；透明图像的 Alpha 不参与 Gamma 校正。

## ROI

1. 选择“ROI → 框选工具”或按 R 开启选区工具。
2. 在图内按住左键拖动，选区包含起点与终点像素；单击选择 1×1 像素。
3. 松开后，画布左上角叠加显示 `[X, Y, 宽, 高]` 和各通道均值。单通道额外显示最小值、最大值。
4. 再次选择“框选工具”关闭工具，已有选区和统计保留。

ROI 边框和中心十字线随缩放倍率分档调整线宽：低于 1 倍为 1 DIP，1 倍至低于 10 倍为 1.5 DIP，10 倍至低于 30 倍为 2 DIP，30 倍及以上为 3 DIP。拖动预览和确认后的选区使用相同规则。

也可选择“ROI → 手动设置”，填写 X、Y、宽、高，在任意 ROI 字段按 Enter 或点击“确定”。X/Y 必须位于图内，宽高为正整数；超出右侧或底部的宽高会裁切并在下次打开时显示实际值。非法输入会给出提示，原选区不变。

拖动中按 Esc、切换窗口或改变布局会结束本次未提交操作，保留上次选区。菜单未打开且无拖动时按 Esc 会清除 ROI 和十字线。只需移除 ROI 时，选择“ROI → 清除 ROI”。

ROI 统计来自原始图像，NaN/Inf 不计入均值与极值。选区内某通道全部无效时，统计显示 NaN。统计叠加层固定在画布内，即使选区被平移到视口之外仍可查看。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+O | 打开图片 |
| Ctrl+0 | 自动适配 |
| Ctrl+1 | 1:1 |
| Ctrl+方向键 | 平移查看区域 |
| R | 切换 ROI 工具 |
| C | 切换图像中心十字线 |
| Esc | 取消拖动；无拖动时清除 ROI 和十字线 |

在输入对话框内，普通按键用于编辑，不会触发 R/C 等查看快捷键；Esc 关闭对话框。选择“帮助 → 关于 ImageViewer”可查看软件信息、程序集版本和 Git 仓库链接，点击链接使用默认浏览器打开：https://github.com/DamoclesQ/ImageViewer 。
